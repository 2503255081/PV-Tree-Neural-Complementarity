### Modification notice

This package contains processed evaluation targets and metadata derived from PVDAQ systems 2107, 9068 and 9069, together with forecasts generated by the manuscript authors. Processing includes quality filtering, quarter-hour aggregation where applicable, site-specific channel handling, capacity normalization and selection of evaluation windows. It is not an official PVDAQ release, and no endorsement by the source providers is implied.

If you redistribute these arrays, preserve this attribution, the license link and the description of modifications. Cite the repository for the author-generated forecasts and the original PVDAQ source for the observations.
